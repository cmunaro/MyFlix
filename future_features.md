# Future features

- [x] **Richer title pages (provider-first):** cached provider synopses, genres, cast, year, and season/episode details where available; actual runtime from local videos. Missing provider fields remain blank; no external metadata service is required.
- [ ] **Storage management:** show free space, warn before downloads fill the disk, and offer cleanup of staging files with a preview before deletion. Preserve library videos and active downloads.
- [ ] **Download notifications:** show an in-app notification when a film or episode has been successfully published to the library and is ready to watch, with a direct Play action.
- [ ] **Chosen cinema monitor:** scope needs clarification—track showtimes at a selected cinema, or follow selected films until they become available for home viewing/download.
- [ ] **Manual import from the web interface:** import movies and series through admin using a folder-style interface, preserving the series/season/episode hierarchy. Validate import paths and never overwrite existing library videos.
